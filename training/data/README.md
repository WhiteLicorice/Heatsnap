# Setup

1. Download the dataset from this link `https://drive.google.com/drive/folders/1UKdOvOqrk_M1j25V6Xm5hJpQirNe8khB?usp=drive_link` or `https://cs.valdosta.edu/~rpmihail/skyfinder/` and place the images (not the masks!) in this directory, inside a `skyfinder_images` folder.

2. Download the dataset metadata `complete_table_with_mcr.csv` and place it in this directory.

3. Run the extraction scripts.
